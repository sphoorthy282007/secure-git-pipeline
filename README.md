# Secure Pipeline Secrets - Set 8

Starter template for the lab exercise.

Before running:
1. Upload these files to a GitHub repository.
2. Add Actions repository secrets REGISTRY_USERNAME and REGISTRY_PASSWORD.
3. Add KUBE_CONFIG for the deployment workflow.
4. Replace YOUR_DOCKERHUB_USERNAME in both workflow files.
5. Ensure your Docker Hub repository `myapp` exists and your Kubernetes cluster is reachable by the runner.

These are templates and require real credentials and cluster access before they can deploy.
Never commit passwords, tokens, or kubeconfig files.
